# PARIS方法

每个design一个XGBoost。候选的分割/布局、CTS、GR端点/路径、线网电气和布线资源描述汇总为候选级向量。

模型学习 `log(1+|DR TNS|) - log(1+|GR TNS|)`。推理时把预测修正加到GR的log代价上，反变换得到预测TNS，并按代价升序排序。训练只在本design训练候选内做3折选参；待预测候选不使用其DR标签。

新design先取得少量DR实测标签，训练专属模型。新增训练数据后累计重训，在固定验证候选上比较，效果更好时更新版本。网页“方法介绍”提供完整路线图。

部署权重保留原实验schema；当前新训练排除文件大小、时间戳和schema版本元数据。五组复现使用各自冻结schema、参数和ID清单，不重新抽样。
