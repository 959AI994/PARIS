# PARIS 单XGBoost工作流

每个design使用一个XGBoost。输入为候选CTS/GR特征、GR端点摘要，以及真实GR线网电气量的确定性统计。模型学习`log1p(-DR_TNS)-log1p(-GR_TNS)`，输出预测TNS和排序。

## 页面

- 输入：保持现有2D→3D→CTS/GR→特征准备流程，或选择已有三个GR表。
- 处理与输出：一个XGBoost完成残差预测；导出完整候选排序与预测TNS。
- PARIS迭代：累计数据，固定验证候选，训练新版本，比较GR与当前版本，可启用/回退及导出。
- 模型评测：Open3DBench固定1000训练/200测试的CTS、GR、PARIS逐设计与Macro τ-b。

## 自训练数据

`features.parquet`、`source_sink.parquet`、`net_load.parquet`、`labels.parquet`、`PARIS_TRAINING.json`。训练标签只需每候选实测`final_tns`；不要求DR wire-delay监督。用于预测的GR目录另含匹配工艺声明`FEATURE_CONTEXT.json`。

网页首次至少36个有标签候选，固定留出至少12个，其余至少24个训练；后续累计训练沿用原验证ID。选参只在训练候选内3折CV完成，目标残差标准化只拟合各折训练部分。训练后独立读取验证GR、封存预测，再评分。

模型格式`paris.single-xgb.1`，原生XGBoost JSON，每design一份；特征schema、目标变换、训练ID、工艺上下文及SHA256随包保存。新design先用本设计实测标签训练，随后新候选推理只需要CTS/GR。

## 现有评测权重

七design bank直接封装1000/200实验的七份原始权重，没有重训。历史输入1002维；为逐值复现保留原schema。新训练排除文件大小/时间戳/schema版本五项元数据，不用测试表现改配方。

评测页的分数是Macro Kendall τ-b乘100，不是正确率百分比。Macro对design等权平均；这200例是已探索seed-17候选池的同设计开发比较。
